# Database Migrations

Before a migration, document the owning module, affected tables, data/backfill impact, deployment order, rollback approach, expected lock/downtime risk, and required tests.

| Migration | Module | Change | Backfill | Deployment order | Rollback | Owner | Status |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

Never deploy a destructive or irreversible migration without an explicit recovery plan and approval appropriate to the risk.
