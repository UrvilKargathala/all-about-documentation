# Frontend Testing

## Required coverage

| Test level | Covers |
|---|---|
| Component/unit | Rendering, state, interactions, formatting, validation |
| Integration | Feature behavior with its data/API adapter |
| Accessibility | Keyboard paths, semantics, names, focus, automated checks |
| End-to-end | Critical user journey in a real browser |
| Failure-path | Errors, retries, permissions, offline/degraded behavior |
| Visual/performance | Important responsive states and defined performance budgets |

Every important feature must test the happy path, invalid input, pending state, API failure, relevant permission denial, and key accessibility behavior.
