# Frontend Accessibility

## Target

- **Standard:** e.g. WCAG 2.2 AA
- **Supported devices/browsers:**
- **Accessibility owner/review process:**

## Required behavior

- Semantic structure and logical heading hierarchy.
- Full keyboard operation, visible focus, and predictable focus movement.
- Accessible names, labels, instructions, and error messages for controls/forms.
- Sufficient contrast; never rely only on color to convey meaning.
- Text alternatives for meaningful images/media.
- Accessible status updates for loading, validation, and asynchronous results.
- Responsive text, zoom support, and suitable touch targets.

Test the primary user journey using keyboard-only navigation before release.
