# Integration Documentation

Create one document per actual provider: `identity.md`, `email.md`, `storage.md`, `payments.md`, `analytics.md`, or `ai.md`.

Each document must define purpose, owner, authentication/configuration, data exchanged, API/webhook contract, timeouts, retries, rate limits, failure/fallback behavior, security/privacy, and tests. Features reference the provider document rather than redefining it.
